# Ahmed Adnane Meddah — Portfolio

Personal portfolio built with **React + TypeScript** and **Vite**.

## Technologies

* React 18
* TypeScript
* Vite
* HTML / CSS
* Canvas API

## Features

* Personal information, education, medals, projects and skills
* Interactive three-floor platformer
* Responsive design
* Dark/light theme
* Progress saved locally

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.
